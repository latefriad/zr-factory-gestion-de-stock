# zr-factory-gestion-de-stock

نظام إدارة مصنع الطباعة عند الطلب (Print-on-Demand) والمخزون وحساب الأرباح الذكي **ZR FACTORY**.

## 🚀 المميزات الرئيسية (Features):
- **📊 لوحة القيادة الذكية (Dashboard):** مؤشرات مالية حية، متابعة المبيعات، المصاريف، وصافي الأرباح.
- **👕 إدارة المخزون والمتغيرات (Blanks & Consumables):** تتبع الملابس الخام حسب اللون والمقاس (Disponibilité)، رولات الـ DTF، البودرة، والأحبار، مع تنبيهات نقص المخزون.
- **📦 تتبع خط سير الطلبيات (POD Workflow - 7 أقسام):**
  1. تأكيد الطلبات عبر الهاتف (CRM)
  2. محطة الطباعة (DTF Station)
  3. محطة الكبس والتثبيت الحراري (Heat Press)
  4. مراقبة الجودة والتغليف (QC & Packaging)
  5. الشحن وشركات التوصيل (Yalidine / ZR Express)
  6. تسليم الطرود وتحصيل الـ COD
  7. إدارة المرتجعات الآلية (Auto-Restock)
- **🧮 حاسبة أمتار الـ DTF الذكية:** حساب التكلفة وهامش الربح بدقة لعدة شعارات في نفس القطعة (صدر، ظهر، أكمام).
- **💰 قسم توزيع الأرباح والشركاء (30% / 30% / 40%):**
  - **رياض (Riad):** 30% من صافي الأرباح
  - **زكرياء (Zakaria):** 30% من صافي الأرباح
  - **صندوق الورشة والمشروع (Project Vault):** 40%
  - نظام سحوبات مباشر يخصم فورياً من رصيد الشريك ومن خزينة المصنع
  - تقفيل الدورة المالية (Clôture de Période) وطباعة محاضر الإقفال الرسمية.
- **☁️ ربط سحابي ثنائي الاتجاه مع Google Sheets:** مزامنة لحظية مع حفظ محلي دون اتصال (Optimistic Offline Cache).
- **📱 متجاوب 100% مع الهواتف الذكية:** شريط تحكم سفلي مخصص للموبايل ونوافذ منبثقة مرنة.
